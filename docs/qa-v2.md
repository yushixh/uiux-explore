## 目标与对应验证

| 可见行为 / 声明 | 功能验证 | 视觉证据 |
| --- | --- | --- |
| TS + Tailwind 重写 | 严格类型检查、生产构建；输出包含所用工具类 | 组件库完整桌面首屏 |

页面是可滚动目录；桌面初始视口应同时展示天气和输入框及其主要控制，小屏按顺序浏览。检查窗口和每个组件内部边界，不能用整体滚动条正常代替局部可见性检查。

## 探索场景

- 快速切换日夜、自动播放时手动选择、隐藏天气后检查停止播放。
- 错误 → 编辑 → 清空 → 再验证；禁用后尝试输入，再恢复默认。
- 长中文标签、长提示、负温度和长城市名；两个实例互不影响。
- 布局检查期间切换状态、过滤组件与改变视口。

## 验收结果

2026-09-10，Chromium 本地检查完成。

- `npm run build` 通过：严格 TypeScript 检查与 Vite 生产构建均成功。生产预览另行验证日夜切换、原生输入与成功反馈，无页面脚本异常。
- 分类、搜索、空结果恢复、搜索快捷键、预览 / 用法、代码复制、重置与移动导航均已操作。复制结果在按钮旁即时反馈。
- 日夜往返、快速反向、自动播放与暂停已验证；检查日、夜和过渡中间状态。减少动态设置下，天气内部动画与非零过渡数量均为 0。
- 输入框已验证键盘输入、Enter 校验、按钮校验、错误后编辑、清空后的焦点、成功和禁用往返。禁用状态同时阻止演示表单提交按钮操作。
- 容器 / 分区 / 元素三层已分别检查。改变视口后，两个组件各 3 个分区的标注坐标、宽高与实际 DOM 差值均为 0。
- 独立组合页未引入 app.css 或 library 模块。两个天气实例状态独立；无图标文本输入、长城市名、负温度及长反馈可正常布局；原生 FormData 收到名称和邮箱。TextField.destroy() 后再次原生输入，不再触发其回调。
- 检查 1440 × 1000、1100 × 850、390 × 844、320 × 740。未发现横向页面溢出或组件边缘越界。320 宽的面板按钮曾出现换行，已修正并复查。
- 探索覆盖快速日夜反向、演示期间过滤、错误 → 编辑 → 清空、禁用恢复和长内容组合。组件点击意外触发分类的问题已修正为仅监听分类按钮，并回归检查。
- 独立视觉检查覆盖首屏、夜晚、过渡、输入状态、代码、布局检查及小屏。未发现文字与图标重叠、组件内容裁切或小屏控件异常换行。目录按内容纵向滚动；1100 × 850 下部分控制需向下浏览。
- Playwright 测试会话与生产预览服务器已关闭；5173 开发预览保留。
