## 响应式与修复

320 × 740 视口下逐项检查七个组件，页面 clientWidth 与 scrollWidth 均为 305px（另有 15px 滚动条），没有页面横向溢出；目录内部横向滚动保留。桌面宽度下也无页面横向溢出。检查结束已恢复默认浏览器视口。

本轮修复了移动端网格最小内容宽度导致的溢出、Gooey 侧边圆形裁切，以及上游 Image 在重显现途中暂停会丢弃计时的问题。后者由本地适配层保存剩余延迟，恢复播放后继续显现；组件销毁会取消计时。

源码包与仓库 main 存在差异，接入以实际 npm 包为准。Orb 的 32px 声明在已安装引擎中缺少运行时预设，界面只提供已验证的 20 / 64px。
