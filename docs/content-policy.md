# 页面文案审计

2026-09-11：扩展到七项组件后，目录改为侧栏 / 移动端横向导航；新增全局配色、局部配色、混合辅色、明暗与暂停控件，其名称用于执行实际操作。以下“已删除”描述的是 v3，不限制本次用户授权的目录调整。新组件卡片内的笔记与图像为演示内容，金属输入的反馈仅描述本次预览状态。

本次规则：文字必须帮助用户识别对象、执行操作、读取数据或理解当前结果。设计解释与实现说明保存在项目文档，不放入组件预览页面。

## 保留项及删除后的损失

| 页面文字 | 用途 / 删除后的损失 |
| --- | --- |
| daylight. | 识别组件库，并作为回到全部组件的入口 |
| 全部 / 天气 / 输入框 | 可操作的组件筛选项；图标无法独立表达筛选范围 |
| 天气 / 输入框（面板标题） | 标识当前预览对象；多个组件同屏、独立筛选后仍能识别 |
| 搜索组件 | 输入控件的用途；空白搜索框无法说明搜索范围 |
| / | 实际可用的搜索快捷键 |
| 布局 | 开启或关闭布局检查 |
| 容器 / 分区 / 元素 | 选择实际检查层级 |
| 检查标签及宽 × 高 | 标识测得的节点与尺寸；仅在检查模式显示 |
| 预览 / 代码 | 切换可操作组件与集成代码 |
| TypeScript | 标明当前代码语言，帮助正确集成 |
| 复制代码 / 已复制 | 执行动作，以及确认系统剪贴板操作成功 |
| 已选中 / 请按 ⌘C / Ctrl+C 复制 | 剪贴板操作失败后的恢复动作；仅失败时出现 |
| 重置 | 恢复本组件的初始状态 |
| 上海、31° / 26°、晴朗、↑33° / ↓26° | 天气组件的实际展示数据，标识地点、当前天气和高低温 |
| 14:00 / 21:00、当地时间 | 指明天气所对应的时间及其时间语义 |
| 示例数据 | 避免把固定预览数据误读为当前真实天气 |
| 白天 / 夜晚 | 选择天气状态 |
| 电子邮箱、必填 | 指明输入内容与约束 |
| you@example.com | 可输入格式示例，未填写时出现 |
| 验证、↵ | 执行校验；对应实际可用的 Enter 操作 |
| 默认 / 错误 / 成功 / 禁用 | 可操作的输入状态预设 |
| 请输入电子邮箱 | 空值校验失败后的下一步动作 |
| 请输入有效邮箱 | 格式错误的纠正动作 |
| 邮箱格式正确 | 校验成功反馈，仅在验证或成功预设后出现 |
| 未找到组件 / 清除筛选 | 无结果反馈与直接恢复操作 |

隐藏的跳转链接、页面标题、按钮名称、搜索结果播报、温度播报和字段关联名称用于键盘或辅助技术访问。它们不承担视觉装饰任务。图标按钮保留可访问名称；不能靠删除标签来制造简洁。

## 已删除

- 宣传标题、英文眉题、理念段落、页尾签名和“持续打磨”等无可核验状态。
- 侧栏、工作空间卡片、重复分类及版本计数。
- 面板英文复述、组件功能说明、状态解释小圆点、重复底部说明。
- 输入框的保管承诺、品牌式提示、优点列表及装饰图标。
- 天气城市名的英文复述；location 成为可选数据，不需要时整个局部分组隐藏。
- 设计基础介绍区与实现技术说明；原说明移交架构文档。

## 实现约束

PreviewPanel 的类型接口已移除 description、english 和 footer 文案槽。组件注册表统一提供名称与搜索数据，页面仅负责组合；新增文案不能通过预览外壳的默认说明槽自动进入页面。
