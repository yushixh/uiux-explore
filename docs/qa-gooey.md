# Gooey 滑动选择修复与复验

日期：2026-09-11。范围：液态交互的滑动选择、展开菜单及其工作区控制。

## 原因与修复

已安装的 liquid-gooey 0.2.1 在 `effect="move"` 时使用 ObservedItem：它测量子元素的实际位置，不处理传入的 x / y。原实现只更新 x，因此按钮选中状态改变了，实际色块却留在首项。暂停时改走另一条实现路径，导致表现不一致。

现在由子元素的 CSS transform 执行位移；Liquid.Item 在正常、暂停和低动态时均使用 observe 路径。暂停 / 低动态时取消过渡及弹性效果，仍允许直接选择，不会回到首项。

按钮和指示器宽度按容器等分，不再依赖 76px 的固定步长。另修正浅色日光混色底色的可读性：保留配置的 onAccent，必要时适当调整底色明度，使选中文字对比度至少为 4.5:1。原值实测约 3.86:1。

## 实际 Browser 操作

- 日 → 月、月 → 日，以及快速来回连点：最终色块与最后选择一致。
- 暂停后切换、恢复播放：选项位置不回到首项。
- Tab / Space 键盘操作：焦点与选中反馈正常。
- 海蓝主色 + 鸢紫辅色、独立深色：保留选择位置；深浅主题的文字颜色正常更新。
- 代码 / 预览往返：保留选择，代码页可打开。
- 展开菜单的图片、链接选择均显示正确反馈；收起与重置正常。
- 390px 手机视口：页面宽度没有横向溢出，滑动选择可用，展开的三个圆形完整可见。
- 生产页面与手机检查页没有捕获到 console error / warn。

本轮未做真实触屏设备、Safari / Firefox 验证，也未扩展为全站所有组件的完整验收。
