## Before you start
Ask which legal, support, company, and product links the user's site needs, and what footer tone fits the brand. Build only the relevant set.

Create a minimal footer with a centered copyright or ownership line and a compact row of secondary links beneath it. Use generous top padding, small neutral sans-serif type, and plenty of whitespace. Set the background to `#fafafa`, primary footer text to `#8a8a8a`, link text to `#999999`, and hover text to `#333333`; use no heavy borders, or a barely visible `#eeeeee` divider. Keep text 11–13px, use 16–24px gaps, and wrap links gracefully on narrow screens. Ensure all links have clear focus and hover states.

### Never
- Never use logos, product names, copy, illustrations, or imagery from the reference.
- Never include irrelevant legal or marketing links.
- Never make the footer visually louder than the page content.
