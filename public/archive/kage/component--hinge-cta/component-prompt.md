## Before you start
Ask what the user's product and brand are, then apply the principles below to their context rather than reproducing this reference.

Create a light careers or community CTA with a two-zone layout: a compact left text column containing an eyebrow, large serif heading, short sans-serif copy, and pill CTA; and a horizontally scrolling media strip on the right. Use 2–3 portrait-oriented rounded image cards with consistent gaps, allowing the final card to be partially clipped to signal horizontal continuation. Align the text vertically around the image midpoint. Use an off-white background `#F8F7F4`, dark text `#171717`, 8px image radius, 24px minimum gaps, and a dark pill button. Make the image strip draggable/swipeable and keyboard navigable, with no intrusive scrollbar.

Never use the reference logo, product name, exact labels, copy, illustrations, or imagery.
