## Before you start
Ask what the user's product, audience, and brand are, then apply the principles below to that context rather than reproducing a restaurant-booking site.

Create a category section with a single featured browse card. Follow these rules:
- Use a clear 18–20px semibold heading and place the card directly below with a comfortable 16–20px gap.
- Keep the card narrow rather than stretching it across the page; this communicates a browseable collection even when only one item is shown.
- Use a landscape thumbnail, bold title, muted metadata, a small rating/activity row, save icon, and an outlined secondary action.
- Use a white card with #e1e3e6 border, 5–6px radius, subtle shadow, and 12px internal padding. Keep the surrounding background white and allow intentional whitespace.
- If more items exist, make the row horizontally scrollable; otherwise avoid inventing empty placeholder cards.

Never: use logos, product names, copy, illustrations, imagery, or exact visual assets from the reference.
