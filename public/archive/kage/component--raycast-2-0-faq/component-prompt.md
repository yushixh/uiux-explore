## Before you start
Ask what questions users have about the product, setup, requirements, migration, or support. Apply these principles to that product rather than reproducing the reference.

Build a centered FAQ section on a black background. Use a clear 24px heading in #eeeeef with generous space above and below. Constrain the accordion to a readable max width of roughly 490px. Each row should be a full-width button with 16px vertical padding, a thin bottom divider in #1d1f21, a 13px semibold question in #eeeeef, and a small chevron aligned to the far right in #b4b4b8. Keep row spacing calm and consistent. Implement accessible accordion behavior with keyboard support, aria-expanded, animated height/opacity for answers, and only one open item if that suits the product. Answers should use 13px muted gray text and never disrupt the overall rhythm.

Never: use logos, product names, copy, illustrations, or imagery from the reference.
