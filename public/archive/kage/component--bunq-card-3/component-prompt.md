## Before you start
Ask what the user's product, audience, and brand are, then apply the following principles to that context.

Create a business-focused product section using a clear mobile narrative: bold heading, one-line supporting copy, wide dark pill CTA, then a large rounded image frame. Keep the section on a black background with 12px page gutters and 16px media radius. Choose an original human-centered image that conveys work, confidence, or collaboration, and use object-fit: cover with a crop that preserves the subject's face and context. Maintain the same type scale, button height, and vertical rhythm as the rest of the page so the repeated pattern feels intentional.

### Never
- Never use the reference logo, product name, copy, illustrations, or imagery.
- Never reuse the reference portrait or composition.
- Never make the business section feel like a separate visual system.
