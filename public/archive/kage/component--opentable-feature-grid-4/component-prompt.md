## Before you start
Ask what the user's product, audience, and brand are, then apply the principles below to that context rather than reproducing a restaurant-booking site.

Create a compact experiences browse section. Follow these rules:
- Use a 18–20px heading and a single narrow card or horizontally scrolling row below it.
- Give the card a strong landscape image, then title, venue/category, price or starting value, and a clear text or button action.
- Separate the information layers with a light divider and keep the action visually quieter than the primary reservation action elsewhere.
- Use #fff surfaces, #e0e2e5 borders, 6px radius, charcoal text, muted gray metadata, and the same accent red #c53c50 for interactive emphasis.
- Provide hover elevation and keyboard focus; on mobile preserve image prominence and avoid shrinking text below accessible sizes.

Never: use logos, product names, copy, illustrations, imagery, or exact visual assets from the reference.
