## Before you start
Ask what makes the user's product trustworthy, what support promise it can make, and which security concepts need explanation. Build an original section using the following design logic.

Design a trust feature band with a small category chip, optional carousel controls, and three rounded cards. Use light neutral and pastel surfaces—warm white, lemon yellow, and soft coral are suitable directions—paired with dark text and bold, simple product scenes. Cards should explain one trust or support benefit at a glance, with a short headline at the top and a visual illustration or UI state anchored below. Keep the card grid aligned to the same max-width and gap system as other feature bands; use 24px radii and 32px internal padding. On mobile, make cards horizontally scrollable with snap points and visible focus states. Avoid overstating security claims; use clear, product-specific language.

Never: copy logos, product names, copy, illustrations, or imagery from the reference.
