## Before you start
Ask what the user's product, audience, and brand are, then apply the following principles to that context.

Create a compact press-recognition strip. Center a short heading above a single responsive row of monochrome publication or partner marks, using white or light gray silhouettes on black. Distribute items evenly, allow horizontal scrolling on narrow screens, and keep logos optically balanced rather than identical in width. Use modest vertical padding and sufficient contrast. Treat every mark as decorative or provide accessible names if it is linked.
