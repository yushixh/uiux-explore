## Before you start
Ask what resolved customer interaction best demonstrates the user's product, then create an original compact example.

Build a small centered example card representing a successfully resolved interaction. Include a small context label or icon, an optional avatar or abstract status marker, a short outcome statement, and supporting metadata. Keep it intentionally isolated in a large whitespace field.

Design rules:
- Card width 260–320px; white background; radius 10–14px; subtle border #E1E1E1 and soft shadow.
- Typography: 14–16px sans-serif for the main outcome, 11–12px muted metadata.
- Use a small neutral icon or approved product asset at the top; keep the content scannable.
- Add generous surrounding whitespace and optional pale glow only if it reinforces the brand.
- Interaction: card can expand to show the full case or link to a detail page.

Never:
- Never reuse the reference person's photo, words, logo, product name, or date.
- Never expose private customer information.
- Never make the card look like a full dashboard.
