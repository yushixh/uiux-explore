## Before you start
Ask what the user's product and brand are, then apply the principles below to their context rather than reproducing this reference.

Create a split feature section with a 48/52 or 50/50 grid. Put one large, edge-contained media panel on the left with a modest 8px corner radius and `object-fit: cover`; place an eyebrow, large serif heading, and readable sans-serif paragraph in a vertically centered column on the right. Let the media and text share the same visual center, with generous internal spacing and no unnecessary card chrome. On mobile, stack the image above the content. Approximate colours: background `#F8F7F4`, text `#171717`, muted text `#595959`, radius `8px`. Include an optional text CTA only if the product needs one.

Never use the reference logo, product name, exact labels, copy, illustrations, or imagery.
