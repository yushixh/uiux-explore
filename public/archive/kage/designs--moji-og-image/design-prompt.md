## Before you start
Ask the user what product this card is for, who the audience is, and what brand assets they already have (name, wordmark, colours, typefaces, an existing app screenshot). Wait for the answers before designing. Everything below is applied to *their* product with placeholder branding and copy — never to the reference product.

Deliverable: a single social/OG image at exactly **1200×630**. Build it as HTML/CSS sized to that canvas and render to PNG (e.g. a fixed 1200×630 body screenshot via Playwright/Puppeteer), or as a standalone SVG. All text must be real, selectable text or vector — no rasterised placeholder lorem except the app screenshot itself.
