## Before you start
Ask what the user's product is, who it serves, and what its brand personality and primary conversion goal are. Then apply the following principles to that product rather than copying the reference.

Build a slim responsive top navigation for a premium B2B software site. Use a centered max-width container with a small wordmark area on the left, a sparse horizontal set of text links in the middle, and two compact actions on the right: a low-emphasis sign-in control and a dark primary CTA. Use generous horizontal breathing room, 12–14px neutral sans-serif navigation text, and a black/near-black #151817 primary button with a subtle 2–4px radius. Keep the header white or warm white #fbfbf9, approximately 48–72px tall, with no heavy border; add a sticky state only if it improves usability. Collapse links into a simple menu on small screens.

Never use logos, product names, copy, illustrations, or imagery from the reference.
