## Before you start
Ask what the user's product, feature set, and brand system are, then use those answers to create an original feature section.

Build a vertically stacked feature showcase with a centered section heading and three alternating or consistently aligned feature rows. Each row should have a text column and a large soft-gray visual/card placeholder column, with clear titles, concise benefit-led copy, and a compact black pill CTA. Use a white background, near-black #090909 text, muted gray #F5F5F7 visual surfaces, 18–24px rounded corners, and a generous 120–180px vertical rhythm between rows. Constrain content to roughly 660px and keep text around 16px with 1.45 line-height; use 28–32px feature titles. On mobile, stack text above visuals and retain comfortable 32px side padding. Make the visual areas ready for product screenshots or animation without depending on them.

### Never
- Never use logos, product names, copy, illustrations, or imagery from the reference.
- Never reproduce the exact feature names or financial claims.
