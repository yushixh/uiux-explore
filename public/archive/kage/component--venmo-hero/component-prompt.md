## Before you start
Ask what the user's product, audience, brand, and primary conversion goal are, then adapt this structure to that context.

Create a full-width hero directly beneath the navigation using a vivid sky-blue background close to #4BAEF0, with a large centered black headline, one-line supporting copy, and a small disclaimer beneath. Place a wide 16:9 media panel below the text, inset from the page edges, with a 24px rounded corner and an image/video placeholder using the user's own asset. Add a small floating QR or secondary action card near the media panel's right edge, plus a discreet circular play/pause control inside the media. Use bold, friendly sans-serif type, approximately 42–48px for the heading and 14–16px for body text. Give the section generous top and bottom padding and make the media scale to one column on mobile.

### Never
- Never use logos, product names, copy, illustrations, or imagery from the reference.
- Never reuse the reference lifestyle image or QR content.
