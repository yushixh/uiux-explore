## Before you start
Ask what the user's product, audience, and brand are, then apply the following principles to that context.

Build a compact promotional CTA section for a defined audience segment. Center a bold white headline, one short supporting sentence in light gray, and a wide pill-shaped button below. Use black (#000000), generous top and bottom padding, a 12px mobile gutter, and a light button surface with dark text. The section should feel like a clear pause after richer visual content. Make the button large enough for touch and provide visible hover, focus, and pressed states.

### Never
- Never use the reference logo, product name, copy, illustrations, or imagery.
- Never assume the same audience segment or offer.
- Never add extra navigation that competes with the primary action.
