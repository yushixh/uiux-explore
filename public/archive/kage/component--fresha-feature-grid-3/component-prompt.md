## Before you start
Ask what the user's product and brand are, then apply the principles below to that context rather than reproducing this reference.

Build a trending-content carousel using the same established listing-card grammar for consistency. Include four visual cards with image thumbnails, editorial badges, favorites, star ratings, and short business metadata. Align the heading to the same content grid as the other rails and preserve generous bottom spacing before the next major section. Use responsive horizontal overflow instead of shrinking cards below a readable width.

Never: use the reference's logo, product name, exact copy, illustrations, imagery, or branding.
