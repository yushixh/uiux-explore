## Before you start
Ask what the user's product and brand are, then apply these principles to that context rather than reproducing the reference.

Create a light, editorial AI feature section. Start with a centered eyebrow and large two-line serif heading, followed by a wide lead feature with a short title, explanatory paragraph, link CTA, and a large pale product UI mockup. Follow it with a two-column grid of smaller feature cards; repeat this pattern for a second full-width feature and another two-column row. Keep each feature self-contained with centered copy above a softly framed interface preview, generous vertical spacing, and subtle fades or shadows instead of heavy card chrome. Use white and very light gray surfaces (#FFFFFF, #FAFAFA, #F4F4F4), black typography, muted gray body text (#777777), 24–40px section gaps, 12–16px preview radii, and 12–14px sans-serif supporting text. Make “Learn more” links visually consistent and keyboard accessible.

Never use logos, product names, copy, illustrations, or imagery from the reference.
