## Before you start
Ask the user what product the card is for, who it targets, and what brand assets they have (name, logo mark, brand colours, tagline/headline copy). Wait for the answers; use a neutral placeholder name and copy if they have none.

## Task
Produce a single **1200×630 Open Graph social card** image (e.g. as an HTML/CSS file rendered to PNG, or a self-contained SVG). Composition inspired by a dark, glowing hero card:

## Page structure
- **Canvas**: 1200×630, near-black background (#050505).
- **Background art**: a symmetrical "wing" of luminous streaks — 3–5 curved ribbon shapes rising from the bottom-left and bottom-right corners, gradient from deep red (#7a1600) at the outer edges to bright orange (#ff8a1e) along the lit curve, with soft gaussian glow/blur. Keep the centre of the canvas a dark, empty void.
- **Text block**, centered both axes in the dark void, top-to-bottom:
  1. Small wordmark lockup (~32px): a simple abstract glyph (dot + rounded shape) beside the product name in bold white rounded sans.
  2. Headline, two balanced lines, ~64–72px, white, medium-weight humanist/rounded sans, tight line-height (~1.1).
  3. Subhead, two lines, ~26px, ~65% white/gray, wider line-height, max-width ~600px.

## Design language
- Strict three-tier hierarchy: wordmark → headline → subhead, all centre-aligned, generous vertical spacing between tiers (~40–60px).
- All colour comes from the background art; text is pure white or muted gray — no coloured text.
- Rounded, friendly sans-serif throughout; the same family for all three tiers, differentiated only by size and opacity.
- Symmetry: background plumes mirror left/right so the centred copy sits in a calm axis.
- No UI chrome, no buttons, no borders — this is a poster, not a page.

## Never
Never copy the reference's brand name, glyph, headline or subhead copy; use the user's own branding or clearly placeholder text. Never present the result as the reference product.
