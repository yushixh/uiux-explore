## Before you start
Ask what channels, workflows, and product capabilities matter to the user's customers, then express them through original examples.

Build a two-column feature section that explains the product through contrasting use cases. Each column should have a concise serif title, one or two lines of supporting copy, and a large visual mockup beneath it. The pair should communicate both the problem and the product's ability to resolve it.

Design rules:
- Layout: two equal columns with a 24–40px gap; stack vertically on mobile.
- Typography: serif feature titles around 25–32px; sans-serif descriptions at 13–15px with a restrained line length.
- Visuals: use original chat, email, dashboard, or workflow mockups in softly rounded frames; keep UI text legible but secondary.
- Colour: mostly white UI surfaces with pale grey #F2F2F2 and pale mint #E7F4E9 accents; subtle blurred colour glow may sit behind visuals.
- Spacing: align titles and descriptions, then give each visual generous vertical room; include a small tab or progress indicator below if the section is interactive.
- Interaction: tabs can switch examples; animate content with a short fade/slide and preserve keyboard access.

Never:
- Never reuse the reference copy, UI screenshots, product name, or imagery.
- Never invent a complex dashboard when a simple illustrative state communicates better.
- Never let decorative glow reduce contrast or readability.
