## Before you start
Ask what the user's product, audience, and brand are, then apply the following principles to that context.

Create a stacked benefits section for a consumer finance or software product. Start with a large white heading and a short supporting sentence, then show three or four feature rows separated by thin muted rules (#555555). Each row should have a concise title, optional one-line explanation, and enough vertical padding for comfortable tapping. Use a black background, white primary text, muted gray secondary text, 12px side gutters, and 24–32px section spacing. Let rows expand or collapse if content is longer, with a clear focus and active state. Keep the hierarchy calm and editorial rather than card-heavy.

### Never
- Never use the reference logo, product name, copy, illustrations, or imagery.
- Never copy the exact feature names or ordering.
- Never turn every row into a brightly colored card.
