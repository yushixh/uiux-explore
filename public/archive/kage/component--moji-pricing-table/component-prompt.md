## Before you start
Ask which platforms the user's product supports, which option should be recommended, and what install or licensing details users need. Ask for the brand's button and card styling.

Create a centered download section with a small eyebrow, a large two-line serif heading, a short explanatory subtitle, and a 3-column platform card row. Each card should include a platform icon placeholder, platform name, two-line install description, and a full-width dark download button; allow one platform to contain two package buttons. Add a small recommended badge to the preferred card and a quiet releases/license note below. Use an ivory background #efede7, white cards #fbfaf7, charcoal #202123, muted #77736c, border #d7d4cc, and accent #b42d27. Use 16px radii, soft shadows, 24px padding, equal card heights, and obvious focus states. Stack cards vertically on mobile.

Never: use logos, product names, copy, illustrations, or imagery from the reference.
