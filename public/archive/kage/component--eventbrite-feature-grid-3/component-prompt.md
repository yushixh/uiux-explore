## Before you start
Ask what the user's product, audience, geographic structure, and brand are, then apply these principles to that product rather than reproducing the reference.

Build a lightweight regional discovery section on a pale neutral background. Include three vertically stacked groups with bold 18–20px headings and rows of compact destination links. Render each link as a white or near-white pill/card with 12–14px semibold text, generous horizontal padding, and a small northeast-arrow affordance. Use 32–44px spacing between groups, 10–12px gaps between links, and allow each row to wrap naturally. Keep the layout within a centered 832px container and use dark navy #17162d headings, black link text, and subtle #f0f0f2 separation. On mobile, use two-column or wrapping rows rather than overflow unless the destination set is intentionally scrollable.

Never: copy logos, product names, exact copy, illustrations, or imagery from the reference.
