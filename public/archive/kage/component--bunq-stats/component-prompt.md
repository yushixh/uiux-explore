## Before you start
Ask what the user's product, audience, and brand are, then apply the following principles to that context.

Build a trust-statistics section with a centered heading and supporting line followed by three stacked cards. Each card should have a soft, high-saturation gradient background, a small circular icon badge, a large numeric value, a bold descriptor, and one muted explanatory sentence. Use 12px gutters, 16px radius, 16–20px gaps, and generous internal padding. Choose an original palette such as green-to-teal, blue-to-indigo, and coral-to-amber while keeping text highly legible. The numbers should be the visual anchor and the supporting copy should clarify what is being measured. Add subtle hover elevation without making the cards feel like buttons.

### Never
- Never use the reference logo, product name, copy, illustrations, or imagery.
- Never invent unverifiable trust claims for a real financial product.
- Never sacrifice contrast for decorative gradients.
