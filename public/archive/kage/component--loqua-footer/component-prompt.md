## Before you start
Ask which pages, resources, social channels, and localization options the user's product actually needs. Build a concise footer around that information.

Create a warm ivory footer (`#faf8ee`) separated by a subtle top border. Use a responsive multi-column container: a brand/about column with a one- or two-line description and small social/language controls, followed by three compact link groups with uppercase or tiny muted category labels and 11–13px links. Use generous horizontal padding, 48–64px top and bottom padding, and a 24–32px column gap. Keep typography quiet and functional; align link baselines and avoid excessive decoration. On mobile, stack the brand column above collapsible or vertically spaced link groups.

Never:
- use logos, product names, copy, illustrations, or imagery from the reference
- include dead links or irrelevant legal/navigation groups
- make the footer compete with the main CTA
