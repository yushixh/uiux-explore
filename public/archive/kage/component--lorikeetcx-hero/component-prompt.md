## Before you start
Ask what the user's product, brand voice, audience, and primary conversion goal are, then create an original hero using the principles below.

Build a spacious centered hero section for a sophisticated B2B software product. Use one large two-line editorial headline, a short explanatory paragraph beneath it, and one centered pill CTA. The section should feel confident and restrained, with substantial whitespace and no competing visual elements.

Design rules:
- Layout: full-width section with a centered content column; headline max-width around 620px and body max-width around 420px.
- Typography: high-contrast serif or elegant display face for the headline, approximately 47–58px desktop with tight line-height; supporting copy in a clean sans-serif at 14–16px.
- Colour: warm white #FFFFFF or #FCFCFB background, near-black #111111 text, muted body text #303030.
- Spacing: generous top padding after navigation, 18–24px between headline and copy, 26–34px before CTA, and enough bottom whitespace to transition calmly into the next visual.
- CTA: dark near-black pill #171717 with white label, 14–16px horizontal padding, radius 999px.
- Responsive behaviour: scale headline fluidly and preserve a narrow readable measure on mobile.

Never:
- Never reuse the reference headline, product name, logo, copy, imagery, or illustration.
- Never add a hero image if the user's product does not need one.
- Never use multiple competing CTAs.
