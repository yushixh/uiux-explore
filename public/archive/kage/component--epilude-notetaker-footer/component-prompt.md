## Before you start
Ask for the user's site map, primary navigation groups, support links, and any status message they want displayed. Build the footer around that information.

Create a dark multi-column footer with a restrained max-width inner container. Use five compact link groups with small uppercase or medium-weight group labels and vertically stacked low-contrast links. Keep columns aligned on a desktop grid and collapse them into accordions or stacked groups on mobile. Add a small status line near the lower left with a green dot, using it only if the product has a meaningful operational or availability message. Use #1a1a1a for the footer surface, #deded8 for headings, #92928e for links, #303030 for dividers, and an accessible green accent around #35c58a. Keep line height generous enough for scanning and add hover underlines or color transitions.

Never: use logos, product names, copy, illustrations, or imagery from the reference.
