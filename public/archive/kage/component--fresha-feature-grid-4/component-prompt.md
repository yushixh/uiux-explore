## Before you start
Ask what the user's product and brand are, then apply the principles below to that context rather than reproducing this reference.

Build a business-oriented product showcase in a two-column layout. On the left, place an oversized headline, short value proposition, dark pill CTA, and a compact trust/review proof row. On the right, show an abstract software dashboard mockup with a calendar or workflow grid, layered cards, rounded corners, and soft lime/lavender glow behind it. Use a pale warm background (`#fbfaf6`) with a bright accent glow (`#d8ff3f` or a product-appropriate equivalent). Keep the visual hierarchy asymmetric: text should be easy to scan while the mockup communicates capability. Stack on mobile with text first.

Never: use the reference's logo, product name, exact copy, illustrations, imagery, or branding.
