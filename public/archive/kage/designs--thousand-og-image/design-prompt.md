## Before you start
Ask the user what product the card is for, who will see it when the link is shared (X, Slack, LinkedIn, iMessage), and what brand assets already exist: product name, a mark or logo, brand colours and typeface. Wait for the answers before designing; everything below is applied to their product, not to the reference. If they have no assets, invent a neutral placeholder name and mark and say so.

## Page structure
Produce a single 1200×630 social card — either a self-contained HTML file sized 1200×630 that can be screenshotted to PNG, or an SVG with `viewBox="0 0 1200 630"`. Top to bottom it is intentionally sparse:

1. **Canvas**: a flat warm-cream background (#F2EDE3-ish, derived from the user's lightest brand neutral) filling the whole frame. No border, no vignette, no gradient.
2. **Focal lockup** (the only content): one horizontal row, optically centered both axes (vertical centre sits at ~50% of the canvas height). Left: an abstract brand mark about 190px tall, built purely from rounded, pill-like shapes with one element filled in the accent colour. Right: the product name as a wordmark-style headline, ~140–160px, with a ~50px gap between mark and text. Cap height of the type should visually match the mark's height.
3. **Negative space**: nothing else. No tagline, no URL, no product screenshot. The empty field is part of the composition. (Only if the user explicitly asks for a supporting line, add one small line centred below the lockup; the reference keeps the card brand-only.)

## Design language
- **One focal point.** A single centered lockup carries the whole card; nothing competes with it. Resist adding sections, stats or imagery.
- **Generous emptiness.** 60–70% of the canvas is background. Margins around the lockup should be at least a quarter of the canvas width.
- **Warm paper, not white.** Ground the card in a cream/beige tone (~#F2EDE3) with near-black ink (~#1B1814) for type and the mark, plus exactly one accent colour (~#F0B32F or the user's accent) used once — on a single element of the mark, never on the wordmark.
- **Type.** One family only: an extra-bold rounded geometric sans with soft terminals, set in sentence case with slightly tight tracking. Scale it so the wordmark dominates — the type IS the card.
- **Pill geometry.** A consistent large radius (fully rounded, pill-like) across the mark's bars and glyph corners; that shared radius is what makes mark and type feel related.
- **Flatness.** No gradients, shadows, strokes-as-decoration, borders or texture. Depth comes only from the accent colour and scale contrast.
- **Interaction/motion:** none — it is a static card; ensure it reads at 200px wide as well as full size.

## Never
Never reproduce the reference's bracket-with-three-bars glyph, the "Thousand" wordmark, or its exact name and copy — replace all of it with the user's (or placeholder) branding. Never present the result as Thousand or reuse its logo, illustrations or icon set.
