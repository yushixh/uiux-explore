## Before you start
Ask what the user's product and brand are, then apply the principles below to their context rather than reproducing this reference.

Build a dark testimonial section with substantial top and bottom padding. Add a small eyebrow at the top, then a large serif quotation set to a readable measure of roughly 620px and a compact attribution beneath it. Use a large decorative opening quotation mark, but keep it typographic rather than illustrative. Add thin horizontal carousel indicators along the bottom; the active segment should be brighter than inactive segments. Use a near-black background `#191919`, warm-white text `#F5F2EE`, muted metadata `#C8C4C0`, and 1px separators `#4A4A4A`. Support keyboard-accessible previous/next controls and pause any automatic rotation.

Never use the reference logo, product name, exact labels, copy, illustrations, or imagery.
