## Before you start
Ask what the user's product, audience, and brand are, then apply the following principles to that context.

Build an accessible segmented tab switcher for several audience journeys. Center it within a spacious black section, using compact rounded tab pills with a dark charcoal inactive state and a subtly tinted accent active state. Keep labels short, use 8–12px gaps, and provide clear keyboard navigation, focus styling, and aria-selected state. The tab group should be visually lightweight but easy to discover, with the selected content rendered immediately below or in the next section. Use white text and muted gray inactive text.

### Never
- Never use the reference logo, product name, copy, illustrations, or imagery.
- Never copy the reference audience labels.
- Never create tabs that merely look interactive without changing content.
