## Before you start
Ask what the user's product and brand are, then apply these principles to that context rather than copying the reference.

Build a long-form workflow section on a clean white background. Start with a large serif statement aligned toward the content column, then present three vertically stacked modules representing stages of a user's workflow. Each module should pair a short stage label, serif subheading, and concise sans-serif explanation with a large rounded product mockup or abstract visual. Alternate or consistently align the media column, but maintain one strong editorial grid and generous vertical separation. Use subtle borders, 16–24px corner radii, restrained shadows, and a mostly neutral palette with one contextual accent per visual. Make the modules responsive by stacking text above media on small screens.

Never:
- use logos, product names, copy, illustrations, or imagery from the reference
- reproduce the three reference stage names or interface screenshots
- sacrifice whitespace for excessive feature detail
