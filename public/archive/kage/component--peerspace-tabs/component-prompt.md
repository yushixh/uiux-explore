## Before you start
Ask what the user's product, audience, and brand are, then adapt this local discovery directory to their categories and markets.

Create a warm off-white (#F5F1E8) location directory with a bold two-line heading and small arrow controls. Add a single-line tab bar of categories with an active tab marked by a dark underline; allow horizontal scrolling when needed. Below, lay out location links in three balanced columns, each with a bold place name and tiny uppercase region metadata. Finish with a dark filled action button. Use 48–64px heading type, 14–16px tab labels, 8px vertical row gaps, subtle rules, and responsive one-column stacking.

Never: use the reference logo, product name, exact copy, illustrations, imagery, or distinctive brand assets.
