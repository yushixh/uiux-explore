## Before you start
Ask what the user's product, audience, and brand are, then apply the following principles to that context.

Build a mobile product-story card with a large lifestyle image above a dark text panel. Use a 12px outer gutter, a 16px radius, and a tall media area with object-fit: cover. The image should communicate the product in everyday use without needing much text. Beneath it, add a bold white title, a short muted description, and one wide pill button in a slightly lighter charcoal (#2b2b2b). Use a black page background and preserve generous padding in the caption panel. Ensure the whole card feels like one cohesive module, with image and caption sharing the same radius.

### Never
- Never use the reference logo, product name, copy, illustrations, or imagery.
- Never reuse the reference photograph or its exact crop.
- Never overload the card with multiple competing calls to action.
