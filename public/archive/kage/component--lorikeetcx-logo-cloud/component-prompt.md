## Before you start
Ask which customer, partner, or integration logos the user's product is allowed to display, then apply this structure with only approved assets.

Build a restrained logo cloud in two horizontally distributed rows beneath a testimonial or stats section. Use monochrome or low-contrast wordmarks with consistent visual height and generous spacing so the strip supports trust without stealing focus.

Design rules:
- Layout: centered max-width container, 5–7 logos per row on desktop, wrapping or horizontal scrolling on mobile.
- Typography/assets: normalize logos to a shared 18–24px visual height; use grayscale or #202020 at 70–85% opacity.
- Background: white or warm white; no heavy container.
- Spacing: 28–44px horizontal gaps and 22–30px row gap.
- Interaction: optional opacity increase on hover; logos may link to customer stories.

Never:
- Never reuse logos from the reference.
- Never imply endorsement without permission.
- Never distort logos or mix wildly different visual sizes.
