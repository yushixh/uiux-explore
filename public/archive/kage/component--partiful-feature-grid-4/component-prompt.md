## Before you start
Ask what the user's product and brand are, then apply the principles below to their context rather than reproducing this reference.

Create an alternating two-feature section:
- Use a subtle pale gradient background and two horizontal rows with generous spacing.
- In the first row, place a framed product illustration/mockup left and copy plus CTA right; reverse the order in the second row.
- Keep each row visually simple: one clear heading, 2–3 lines of benefit-oriented text, and one dark button.
- Use rounded visual frames, soft shadows, and a restrained palette of mint, lavender, and warm pink accents.
- Ensure the images have descriptive alt text and the mobile order is text followed by visual for each feature.

Never:
- Never use logos, product names, copy, illustrations, or imagery from the reference.
- Never reproduce the specific social/photo compositions.
