## Before you start
Ask what the user's product, audience, and brand are, then apply the principles below to that product rather than reproducing the reference.

Build a rounded split integration section: an off-white text panel on the left and a vivid accent panel on the right containing an orderly field of circular integration icons. Use a saturated golden-yellow or brand-specific accent for the icon field, with varied icon colors, consistent circle sizes, and intentional spacing. The text side should use a small uppercase eyebrow, editorial serif heading, and short sans-serif explanation. Use a 16px radius, minimal border, and a clean vertical center alignment. On mobile, stack the text above the icon field and reduce the icon count while retaining visual density.

Never use logos, product names, copy, illustrations, or imagery from the reference.
