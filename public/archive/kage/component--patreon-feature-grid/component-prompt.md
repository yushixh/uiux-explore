## Before you start
Ask what the user's product, audience, and brand are, then apply these principles to that context rather than reproducing the reference.

Build a wide editorial feature section on a soft pastel background. Combine an oversized, thin display heading with an asymmetrical collage of 4–5 differently sized media cards, allowing deliberate overlap and varied alignment. Add small captions to media and place concise supporting copy in a quieter corner. Use high contrast dark text, generous negative space, minimal borders, and responsive rules that turn the collage into a clean vertical stack on small screens.

Never: use the reference's logos, product names, copy, illustrations, or imagery.
