## Before you start
Ask what the user's product, audience, and brand are, then apply the principles below to create an original implementation section.

Build a technical implementation section with a clear heading, an introductory paragraph, a concise bullet list of operating goals, and follow-up explanatory paragraphs. End with a compact supporting visualization when appropriate.

### Design language
- Layout: article-width content with a clear heading, bullets aligned to the text column, and a chart or figure separated below.
- Typography: 24–30px heading, 14–16px body, 14–16px bullets, 11–12px figure labels.
- Spacing: 16px after heading, 18–24px around bullet lists, and 32–48px before a supporting figure.
- Colour: canvas `#f8f8f6`, ink `#1e1e1e`, muted notes `#777777`, accent `#3517e8`; use pale accent washes only for emphasis.
- Borders and radius: bullets should not be boxed; figures may use a hairline border and 4px radius.
- Interaction: links and expandable implementation notes should have visible hover/focus states; preserve list semantics.

### Never
- Never reuse logos, product names, copy, illustrations, or imagery from the reference.
- Never make every sentence a bullet.
- Never overuse accent colour in ordinary body copy.
