## Before you start
Ask what capabilities are essential for the user's product and how they should be grouped for the target audience. Use concise original labels and descriptions.

Create a dark specification section with a small chapter eyebrow, large split-style heading, and one short paragraph. Below it, build a 3-column by 3-row grid of feature cells using 1px warm-white borders. Each cell should contain a tiny spec index, a bold uppercase title, and a compact explanation. Use near-black (#0b0d0d), warm white (#f4f3ec), muted gray body copy, and orange only for micro-labels or active accents. Keep all cells equal height, align internal content consistently, and collapse to one column on narrow screens. Add a thin audience/category strip below only if it supports navigation.

Never: copy logos, product names, copy, illustrations, or imagery from the reference.
