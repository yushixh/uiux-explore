## Before you start
Ask what the user's product and brand are, then apply the principles below to their context rather than reproducing this reference.

Build a template gallery:
- Start with a left-aligned section heading and one short supporting line in a constrained content container.
- Place 3–4 equal-width visual cards below, with rounded corners around 10–14px and tightly controlled gutters.
- Let imagery carry most of the visual interest; use consistent aspect ratios and object-cover cropping.
- Add carousel affordances only if more content exists, with visible keyboard focus and touch dragging on mobile.
- Use bold 28–32px heading typography and subdued 15–16px supporting text.

Never:
- Never use logos, product names, copy, illustrations, or imagery from the reference.
- Never copy the specific template artwork.
