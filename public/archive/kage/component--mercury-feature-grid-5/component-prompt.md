## Before you start
Ask what the user's product, audience, and brand are, then apply the following principles to that product rather than copying the reference.

Create a security feature band with an outcome-focused heading and three equal cards. Each card should contain a tall abstract UI or security visualization, a clear security capability title, and brief supporting copy. Use a restrained palette: deep navy #171721, charcoal cards #252532, off-white visuals #f1f1ed, and a cool lavender accent #8585a8. Keep card corners around 8–10px, use subtle borders, and make the cards feel calm and trustworthy rather than alarmist. Stack cards on mobile and preserve minimum text size of 13px.

Never: use logos, product names, copy, illustrations, or imagery from the reference.
