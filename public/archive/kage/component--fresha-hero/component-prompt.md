## Before you start
Ask what the user's product and brand are, then apply the principles below to that context rather than reproducing this reference.

Create a centered discovery hero directly below the navigation. Use a soft lavender-to-pink gradient (`#d9d8ff` to `#ffd7f6`) with generous vertical breathing room. Add a large near-black headline at roughly 44–52px with tight line height, a single supporting sentence, then a wide white search bar divided into 3–4 fields and a dark pill-shaped submit button. Follow it with a small bold live statistic and a secondary app-download pill. Keep the search container max-width around 770px, radius 28px, subtle shadow, and use simple line icons. On mobile, stack the search fields while retaining one prominent action.

Never: use the reference's logo, product name, exact copy, illustrations, imagery, or branding.
