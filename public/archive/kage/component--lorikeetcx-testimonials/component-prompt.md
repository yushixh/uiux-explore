## Before you start
Ask what customer evidence, metrics, permissions, and brand palette the user's product has, then build an original proof section from those inputs.

Create a social-proof section with a centered serif heading and short supporting sentence, followed by an asymmetrical responsive mosaic of testimonial and metric cards. Mix customer quotes with large percentage outcomes so the section feels evidence-led rather than like a uniform logo wall.

Design rules:
- Layout: full-width section with a centered heading block; below it use a 2–3 column CSS grid with varied card spans and staggered rows.
- Cards: soft gradient washes in pale green, yellow, lavender, and white; radius 12–16px; thin translucent border #D9E0D8.
- Typography: serif heading around 32–40px; quote text 16–20px; metric numerals 40–56px; metadata in 11–13px sans-serif.
- Content hierarchy: quote first, person and role anchored at the bottom, customer mark represented only by the user's own approved brand assets; metric cards show the number, label, and source.
- Spacing: 16–20px grid gaps and generous section padding. On mobile, stack cards while preserving varied heights.
- Interaction: optional carousel controls or hover elevation only if there are more testimonials than fit comfortably.

Never:
- Never reuse the reference customer names, logos, quotes, metrics, product name, or photos.
- Never fabricate performance claims; use supplied or clearly labelled placeholder data.
- Never make every card identical in size.
