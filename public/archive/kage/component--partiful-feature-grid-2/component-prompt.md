## Before you start
Ask what the user's product and brand are, then apply the principles below to their context rather than reproducing this reference.

Build a three-row feature narrative:
- Use a light background with each row in a generous two-column grid: one side for a UI mockup, one side for a short heading, explanation, and CTA.
- Alternate the image/text order between rows to create rhythm and keep the page from feeling repetitive.
- Give each row substantial vertical padding, with soft blue/pink ambient gradients behind the mockups.
- UI visuals should look like believable interface snapshots in rounded cards, with layered messages, avatars, and status chips where relevant.
- Use 24–30px headings, 16–18px body copy, and compact black buttons; align text vertically near the visual center.
- Collapse to one column on mobile while maintaining clear reading order.

Never:
- Never use logos, product names, copy, illustrations, or imagery from the reference.
- Never copy the exact chat screenshots or feature claims.
