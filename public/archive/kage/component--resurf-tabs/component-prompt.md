## Before you start
Ask what parts of the user's product need a guided walkthrough and which surface should be the default. Apply these interaction and layout rules to that product.

Build a product-tour section with a centered editorial heading, a short explanatory paragraph, and a compact pill-style tab control beneath it. Tabs should represent distinct product surfaces or workflows, with one clearly active using a white fill, subtle shadow, and darker text while inactive tabs remain muted. Below the tabs, show one large rounded interface preview inside a restrained max-width container and a concise caption underneath. Use a warm off-white background, black-brown heading text (`#242424`), muted gray body text (`#7a7a7a`), pill background `#f1f1f1`, active tab `#ffffff`, and image frame border `#e6e6e6`. Use 12–14px tab text, 16–24px gaps, 12px pills, 18–24px preview radius, and 80–112px vertical section padding. Add keyboard focus states, animated crossfade or short slide transitions between panels, and keep the selected tab accessible on mobile with horizontal scrolling if necessary.

### Never
- Never use logos, product names, copy, illustrations, or imagery from the reference.
- Never make tabs decorative; each tab must change meaningful content.
- Never show an illegible interface preview or rely on hover alone.
