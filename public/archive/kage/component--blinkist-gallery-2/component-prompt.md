## Before you start
Ask what the user's product, audience, and brand are, then apply these principles to that product rather than copying the reference.

Create a lifestyle gallery section with a centered headline and a short supporting sentence. Below it, arrange four portrait-oriented rounded image tiles in a loose horizontal row, each tagged with a small floating context label. Vary tile heights or crops subtly to create editorial rhythm, but keep the row aligned and scannable. Use 18–24px image radius, soft neutral label backgrounds #f4edf2, navy text #073544, and ample white space. On mobile turn the row into a swipeable gallery with visible partial next cards, and provide meaningful alt text.

Never use the reference's logos, product names, copy, illustrations, or imagery.
