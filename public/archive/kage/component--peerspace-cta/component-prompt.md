## Before you start
Ask what the user's product, audience, and brand are, then tailor this conversion moment to their product and audience.

Create a full-bleed image CTA with a centered, vertically stacked headline in large white type and one compact outlined or filled button beneath. Add a dark translucent overlay or carefully chosen image treatment so the text remains readable. Keep the composition calm and spacious, use 48–72px responsive heading typography, 8px-ish button radius, and a clear focus state. The image should crop gracefully across desktop and mobile, with the CTA remaining centered without obscuring the most important subject.

Never: use the reference logo, product name, exact copy, illustrations, imagery, or distinctive brand assets.
