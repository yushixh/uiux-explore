## Before you start
Ask what the user's product, audience, and brand are, then apply these principles to that context rather than reproducing the reference.

Design a spacious feature section with a cool pastel field, a centered oversized headline, and several floating content previews positioned around it like a controlled collage. Keep the headline as the visual anchor, then place a narrow explanatory text block and one dark pill CTA toward the lower left or center. Use rounded media previews, subtle shadows, and clear responsive constraints so decorative cards never obscure the message on mobile.

Never: use the reference's logos, product names, copy, illustrations, or imagery.
