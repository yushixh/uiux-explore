## Before you start
Ask what the user's product, audience, and brand are, then apply the principles below to that context rather than reproducing a restaurant-booking site.

Create a compact tab-and-accordion information module. Follow these rules:
- Place a horizontal tab bar with four topic labels and a thin bottom rule. The active tab uses the accent color #bd3c51 and a 2px underline.
- Below it, use a two-column grid of accordion questions on desktop, stacking on mobile. Each row has a concise question, generous 18–22px vertical padding, and a chevron aligned to the far edge.
- Use 13–14px labels, #30343b text, #737981 inactive text, and #e3e5e7 dividers. Keep the visual density calm and whitespace-led.
- Implement true tab semantics, keyboard arrow navigation, focus-visible rings, and accordion buttons with aria-expanded and animated content.
- Ensure the module can support longer answers without shifting the surrounding layout unpredictably.

Never: use logos, product names, copy, illustrations, imagery, or exact visual assets from the reference.
