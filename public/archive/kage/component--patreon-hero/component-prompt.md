## Before you start
Ask what the user's product, audience, and brand are, then apply these principles to that context rather than reproducing the reference.

Create a full-bleed hero with a darkened, high-impact brand-appropriate visual and a very large lightweight headline anchored near the lower left. Let the typography span multiple lines and interact with the composition, while keeping a small proof point or featured-user label near the opposite side. Add minimal previous/next controls and a scroll cue; make the visual area feel like an editorial carousel without overwhelming the message. Use near-white text, restrained overlays, generous vertical space, and responsive type that avoids clipping.

Never: use the reference's logos, product names, copy, illustrations, or imagery.
