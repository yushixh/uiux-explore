## Before you start
Ask what actions users can trigger quickly in the user's product and which workflows benefit from hands-free or shortcut-driven interaction. Translate those answers into this layout.

Create a second editorial feature group with a centered serif heading and thin rules. Use two or three generous alternating rows. Each row pairs a large rounded demo surface with an adjacent text block: a small abstract accent glyph, an italic serif question or benefit statement, and a short sans-serif explanation. For command-oriented workflows, include a compact numbered list or trigger/action detail beneath the copy. Use the same warm ivory background (`#faf8ee`), pale beige media surfaces (`#f3efe4`), black text, and restrained colored accents such as lavender, coral, or lime. Maintain consistent 16–20px radii, 80–120px row spacing, and a clear left edge for body copy. On mobile, stack media above text and retain generous breathing room.

Never:
- use logos, product names, copy, illustrations, or imagery from the reference
- reproduce the reference's exact workflow wording or illustrations
- let decorative media dominate the explanation
